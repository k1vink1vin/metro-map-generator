# 大台北與桃園路網圖印刷複驗

用專案根目錄的 `TPE_Metro.xlsm` 重現。這版工作簿有 321 筆站碼、270 個圖面站點、15 條路線、21 條路徑與 307 條路網邊。原始站名、座標、轉乘分組、行車順序和配色由工作簿提供。路網包含規劃路線，台鐵與高鐵為工作簿選錄的部分站點。270 個圖面站點都缺英文站名，圖例有標示資料範圍。

## 版式和符號

| 路網版式 | 圖面與驗收重點 |
| --- | --- |
| Geographic | 北向經緯度投影等比例放大，維持座標相對位置，附北箭頭。近鄰站點以小錨點和引線分開。 |
| Taipei 45° | 45° 路線，保留相對地理方向，淡水河作為示意地標。 |
| London 45° | 45° 路線，優先辨識中心密集路網及轉乘，採規律站距。 |
| Moscow Ring | 工作簿定義兩個獨立圓心的正圓環，非環路段採 45°。檢查全圖的地理順序與環線的圓心。 |
| Concentric | 同一圓心的圓弧與放射直線。此工作簿以台北車站為中心，網頁可改選任一站。逐走廊調整站距和錨點，保留鄰近區域的相對方位。 |
| Hex 60° | 路線符合 0°、60°、120° 三軸，保留支線、轉乘和分歧順序。 |

每種路網版式各輸出台北、東京、大阪、莫斯科四種站點符號。色框和色塊沿用對應路徑顏色，淡色路線加深色外邊。大阪的色塊依底色使用黑字或白字。莫斯科的轉乘圓環包含各路徑顏色。路線交叉處用斷開表示無轉乘，轉乘點有專用站點符號。精確重合的直線或圓弧分色並排，依圖例可追蹤每條路線。

## 重現

```sh
npm install
npm run build
npm run qa:geometry
npm run qa:workbook
npx playwright install chromium
METRO_PRINT_PDF=1 npm run qa:print
```

Chromium 驗證使用 Noto Sans CJK TC 或可用的繁體中文字型。若系統已安裝 Chromium，可以設定 `CHROMIUM_PATH`。工作簿 QA 同一行程只算一次各版式，並產生以下檔案。CI 以 `tpe-metro-style-qa` 提供下載。

- `qa-artifacts/*--stations-*.svg` 為 24 張完整圖，沿用網頁實際使用的 SVG 元件和樣式。
- `qa-artifacts/print/*.pdf` 為 24 張單頁校樣，四周留白 10 mm，中文站名字級 4.5 mm。按 PDF 的尺寸原大印製，字級會隨紙張縮放。
- `qa-artifacts/workbook-manifest.json` 包含輸入檔 SHA-256、站名、站碼、路徑順序及配色。
- `qa-artifacts/print-audit.json` 記錄每張圖的頁面尺寸、站名與站牌重疊、站名與路線相交、裁切、站碼和路徑差異。
- `qa-artifacts/geographic-order.json` 記錄每種版式的東西與南北順序正確率，以及淡水、台北車站、南港展覽館、桃園和板橋的具名方位檢查。每軸比較約 3.6 km 以上的差距，示意版式每軸須達 97%。
- `qa-artifacts/moscow-geography.json` 列出莫斯科版全部顯著方向反轉。`moscow--huilong-taoyuan-detail.svg` 用來複驗迴龍與桃園車站的相對位置。

數值檢查涵蓋路徑與錨點順序、實際 SVG 角度、獨立圓心／共圓心、採樣自交、轉乘與支線，以及印刷圖在瀏覽器中排版後的字框。印刷校樣依工作簿資料繪製。站內正式導引的雙語資料與營運單位審核仍待補齊。
